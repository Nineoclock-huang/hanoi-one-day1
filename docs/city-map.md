# 河内城市沙盘

这是一张用于越南语学习游戏的示意沙盘，保留真实地标的主要相对方位，距离、建筑体量和道路经过压缩，不用于导航。咖啡店、酒店、餐馆和公交站是虚拟教学地点。

## 地理参考

- 越南旅游局景点介绍：https://vietnam.travel/things-to-do/11-must-see-attractions-ha-noi
- 河内中心城区参考地图（第 7 页）：https://www.trailsofindochina.com/wp-content/uploads/2019/02/TOI_WelcomePack_VN_GuideBook_Ha-noi_FA2_Digital.pdf

西湖在市中心西北侧；老城区及同春市场位于还剑湖以北；巴亭、升龙皇城和文庙在西侧；河内大剧院在还剑湖东南侧；红河及跨河桥梁位于东侧。模型不是精确测绘或原地图的复制。

## 增加场景

`src/cityData.ts` 是地点和分区的注册表。每个地点有稳定 ID、中越文名称、世界坐标、标注高度、分区、说明和开放状态。坐标 x 向东递增，z 向南递增。

1. 在 `CITY_PLACES` 中加入地点，先使用 `status: 'planned'`。它会自动进入地点查找菜单、标注和介绍卡。
2. 在 `src/cityRenderer.ts` 加入该 ID 对应的模型。通用街区生成会避让注册地点的范围，避免模型重叠。
3. 实现对应业务页面与任务后，再接入 `CityScene` 的场景路由并设置 `status: 'open'`。当前只有 `cafe` 会进入实际任务，新增开放状态不会自动复用咖啡任务。
4. 新区域可在 `CITY_VIEWS` 中设置固定朝向相机的目标与范围。视角支持平移和缩放，不允许旋转。

## 性能与交互

重复建筑、窗户、屋顶和树木使用实例化绘制；相机标注只在视角或画布尺寸变化时重新投影，并按优先级避让。缩小时部分文字标注会隐藏，但全部地点都可从查找菜单进入。无 WebGL 时仍可进入咖啡店，景点说明也可使用。

真实设备仍应关注 WebGL 性能、触摸拖动和双指缩放。现有自动测试覆盖分区选择、缩放命令、地点查找、未开放场景的行为与咖啡店入口。
